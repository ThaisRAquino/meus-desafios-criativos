# 🤖 Meus Desafios Criativos

Repositório com o desafio de **criação de prompt** da trilha [Aceleração Santander - Primeiros passos com IA](https://web.dio.me/track/a3d7df2a-fc6c-47ee-a285-036a69e9639d), da [DIO](https://www.dio.me/).

## 🎯 Sobre o desafio

O objetivo foi montar um prompt claro e completo, juntando as partes trabalhadas no curso:

- **Tipo de conteúdo**: o que a IA deve gerar
- **Público**: para quem é o conteúdo
- **Objetivo**: o resultado esperado
- **Contexto**: as informações que a IA precisa considerar
- **Formato**: como o conteúdo deve ser apresentado
- **O que evitar**: os limites da resposta

## 📄 Prompt final

O prompt está no arquivo [`prompt-final.md`](prompt-final.md). Ele pede um cronograma semanal com exercícios físicos que se encaixe na rotina de trabalho e estudos, com foco em organização e produtividade sem esgotamento.
